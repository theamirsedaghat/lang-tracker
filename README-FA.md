# English Mastery OS — Pre-IELTS Edition

یک داشبورد شخصی **React 19 + TypeScript + Vite PWA** برای ثبت پیشرفت زبان به‌صورت آفلاین‌محور، بدون حساب کاربری، بدون نیاز به سرور/API برای ذخیره داده‌ها.


## نسخه 1.1 — فارسی و انگلیسی (FA/EN)

- دکمه **FA / EN** در بالای برنامه و انتخاب زبان در Settings قرار دارد. تنظیم زبان در `settings.language` ذخیره می‌شود و بین باز و بسته کردن برنامه باقی می‌ماند.
- با انتخاب English، همه متن‌های اصلی به انگلیسی و چیدمان به **LTR** تغییر می‌کند؛ فارسی **RTL** است. تم تیره/روشن و تنظیمات مطالعه مستقل از زبان باقی می‌مانند.
- عددها در انگلیسی با ارقام لاتین و در فارسی با ارقام فارسی نمایش داده می‌شوند. تاریخ‌های خلاصه در فارسی **شمسی** و در انگلیسی **میلادی** هستند.
- **ماه‌های تقویم مطالعه در هر دو زبان میلادی‌اند** چون شبکه روزها و مقدار ذخیره‌شده `YYYY-MM-DD` از ابتدا میلادی بوده است؛ ماه میلادی در زبان فارسی با نام فارسی نشان داده می‌شود و در جزئیات روز، معادل میلادی نیز قابل مشاهده است.
- **ساختار داده و شناسه درس‌ها تغییر نکرده‌اند.** `schema:1` و نام دیتابیس `english-mastery-os-db` با همان نسخه ۱ باقی مانده‌اند. بکاپ‌های نسخه قبل، در Import به فارسی پیش‌فرض تبدیل می‌شوند و می‌توانند بعداً English شوند.
- `src/i18n.ts` شامل فرهنگ متن‌های رابط و توابع تاریخ/عدد است. برای افزودن ترجمه در آینده، واژه/عبارت فارسی را به دیکشنری `EN` اضافه کن.
- با هر تغییر زبان، داده‌ها روی **همان مرورگر و همان مبدأ (origin)** باقی می‌مانند. جابه‌جایی آدرس سایت یا پورت localhost می‌تواند محل ذخیره مرورگر را عوض کند؛ حتماً ابتدا Backup JSON بگیر.

### اعمال نسخه جدید روی پروژه قبلی

1. در اپ فعلی **Settings → Download Backup** را بزن و فایل JSON را در محل مستقلی نگه دار.
2. پروژه را ببند. فایل‌های موجود در بسته جایگزین را در مسیرهای مشابه کپی و اجازه Overwrite بده. فایل جدید `src/i18n.ts` حتماً باید اضافه شود.
3. اگر پوشه `node_modules` قبلاً نصب شده، دستورهای زیر را اجرا کن:

```bash
npm run build
npm run dev
```

4. اگر وابستگی‌ها را نصب نکردی، قبل از این دستورها `npm install` را اجرا کن. برنامه را در **همان آدرس قبلی** باز کن تا IndexedDB قبلی قابل دسترسی بماند.
5. از Settings زبان را تغییر بده و پس از ثبت یک درس، صفحه را Refresh کن تا از ماندگاری زبان و پیشرفت مطمئن شوی.
6. اگر PWA قدیمی را نصب کرده‌ای، بعد از deploy نسخه جدید و فعال‌شدن Service Worker به‌روزشده، ممکن است لازم باشد صفحه را یک‌بار ببندی و باز کنی. حذف Site Data راه ارتقا نیست.

**تست‌ها:** ۱۰ تست Node برای محاسبات، Import سازگار با نسخه قبل، تاریخ‌های دو زبان و ذخیره زبان اجرا و پاس شده‌اند؛ بررسی TypeScript ماژول‌های هسته نیز پاس شده است. نصب npm در محیط آماده‌سازی به رجیستری دسترسی نداشت و `npm run build` کامل به‌دلیل نبود `vite/client` و `vite-plugin-pwa/client` قابل اجرا نبود. تست UI تعاملی روی مرورگر انجام نشده است.


## اجرای برنامه

نیازمندی: Node.js 20.19 یا جدیدتر و اینترنت **فقط برای دانلود اولیه بسته‌های npm**.

```bash
npm install
npm run dev
```

آدرس نمایش‌داده‌شده (معمولاً `http://localhost:5173`) را در مرورگر همان دستگاه باز کن. برای نسخه نهایی قابل نصب:

```bash
npm run build
npm run preview
```

نسخه ساخته‌شده داخل `dist/` قرار می‌گیرد. برای نصب PWA روی گوشی و دسترسی آفلاین، این پوشه باید روی **HTTPS** یا `localhost` عرضه شود؛ باز کردن مستقیم `index.html` با `file://` برای PWA کافی نیست. پس از نصب و یک‌بار بارگذاری کامل، خود برنامه برای استفاده روزمره و ذخیره داده به اینترنت نیاز ندارد.

برای آزمون موتور محاسبات:

```bash
npm test
```

## جلوگیری از نابودی اطلاعات

1. بعد از هر تغییر، داده‌ها با یک صف نوشتن در `IndexedDB` ذخیره می‌شوند.
2. برنامه در همان مرورگر یک Snapshot روزانه (تا 30 روز) و یک نسخه در هر 15 ویرایش (تا 20 مورد) ایجاد می‌کند. این‌ها **همان‌جا** ذخیره‌اند و در برابر حذف داده مرورگر یا خرابی گوشی محافظت نمی‌کنند.
3. از تنظیمات، **دانلود فایل Backup** (JSON) را بزن. آن فایل را در پوشه‌ای خارج از ذخیره مرورگر/روی رسانه دوم نگه دار. برای انتقال به دستگاه دیگر از **بازیابی از فایل** استفاده کن.
4. امکان درخواست `navigator.storage.persist()` وجود دارد. مرورگر ممکن است درخواست را قبول نکند و این قابلیت جای نسخه پشتیبان مستقل را نمی‌گیرد.
5. هیچ بک‌آپ خودکار بی‌صدا به پوشه Downloads/فضای ابری انجام نمی‌شود؛ مرورگر برای این کار مجوز صریح می‌خواهد. نسخه داخلی روزانه بدون تعامل کاربر (در هر بار بازشدن یا ذخیره شدن برنامه) تولید می‌شود.
6. **Sync خودکار بین دستگاه‌ها وجود ندارد.** IndexedDB به دامنه، پروفایل مرورگر و دستگاه وابسته است. برای تبدیل به برنامه آنلاین و چنددستگاهی در آینده باید سیستم ورود کاربر و بک‌اند را اضافه کنیم.
7. حالت ناشناس/Private برای نگهداری مطمئن اطلاعات مناسب نیست. حذف اپ/داده سایت ممکن است همه داده‌های داخلی را حذف کند.

## ارتقای نسخه بعدی

فایل JSON آخرین Backup و کل سورس این پروژه را نگه دار. نسخه‌های آینده می‌توانند از شناسه‌های ثابت درس‌ها و `schema: 1` برای مهاجرت داده استفاده کنند. تغییر تعداد یونیت‌ها یا شناسه‌ها بدون مهاجرت کنترل‌شده می‌تواند رکوردهای قبلی را ناسازگار کند.

## ساختار

- `src/i18n.ts` ترجمهٔ FA/EN و قالب‌بندی اعداد و تاریخ‌ها
- `src/catalog.ts` کتاب‌ها، درس‌ها، ساختار و داده‌های اولیه
- `src/engine.ts` موتور محاسبات هدف روزانه، پیشرفت، شمارش، تخمین و Import validation
- `src/storage.ts` IndexedDB، صف ذخیره‌سازی، Snapshot، Export/Import
- `src/App.tsx` داشبورد، کتابخانه، تقویم، تحلیل و تنظیمات
- `src/styles.css` طراحی واکنش‌گرا و Dark/Light
- `vite.config.ts` پیکربندی PWA و Service Worker
- `tests/engine.test.mjs` آزمون‌های مستقل موتور محاسبات
- `tests/i18n.test.mjs` آزمون‌های دوزبانه و سازگاری بکاپ

## وضعیت اعتبارسنجی

آزمون‌های موتور محاسبات با `npm test` اجرا و گذرانده شده‌اند و فایل‌های TypeScript/TSX از نظر سینتکس بررسی شده‌اند. محیط تولید این بسته به رجیستری npm دسترسی نداشت، بنابراین **build کامل React و آزمون تعاملی مرورگر در همین محیط اجرا نشده‌اند**؛ پس هیچ ادعای تضمین 100٪ بی‌باگ وجود ندارد. برای استفاده پایدار، پس از `npm install` حتماً `npm run build` را اجرا کن و یک Backup آزمایشی را Export/Import کن.

### نکته درباره خدمات خارجی

در نسخه اول هیچ سرویس تحلیلی، تبلیغاتی، ورود کاربر یا API خارجی استفاده نشده است. خود برنامه پس از نصب می‌تواند آفلاین کار کند. npm تنها برای ساخت پروژه به اینترنت نیاز دارد.
